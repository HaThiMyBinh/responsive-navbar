Thu nhỏ cửa sổ trình duyệt xuống dưới 768px để thấy thanh điều hướng chuyển sang chế độ mobile với biểu tượng ☰.

📌 Cách hoạt động

  • 🖥️ Desktop (> 768px): Menu hiển thị ngang, dùng Flexbox.
  • 📱 Mobile (≤ 768px): Menu ẩn, biểu tượng ☰ xuất hiện.
  • 👆 Nhấn ☰: Menu mở ra dọc bằng JavaScript.

🛠️ Kỹ thuật sử dụng

  • display: flex — Căn chỉnh navbar theo hàng ngang
  • @media (max-width: 768px) — Responsive cho mobile
  • classList.toggle("active") — Mở/đóng menu bằng JS
  • position: absolute — Menu mobile trải rộng toàn màn hình
